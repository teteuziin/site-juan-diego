# Juan Diego Creative Studio — site-modelo

Landing page de prospecção criada a partir do portfólio público do Instagram @juandiego.creativestudio (fotografia de casamento, Salvador/BA).

- Galeria editorial: papel off-white, charcoal e âmbar; fotos em moldura passe-partout
- Histórias reais: Lissandra e Matheus (13/11/2026) e Larissa e Josemario (civil, 11/11/2026)
- 3 vídeos com som original (estúdio, bastidores e reel de casamento)
- Contato pelo direct do Instagram (nenhum WhatsApp público) + formulário com resumo para copiar
- Intro temática de moldura, vídeos que pausam ao sair da tela, cursor padrão do sistema

Site estático: index.html + media/*.mp4.
